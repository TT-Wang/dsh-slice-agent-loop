# Effort 阶梯实验与 low 默认档裁决（2026-09-01）

## 背景

留存系列账本分解显示：slice 的输出膨胀是**均匀的每调用税**（s14b 逐轮 1.7–2.1×，steps 数与 transcript 臂几乎相同）——"编译式案卷重定位 + 逢事验证认识论"的固定成本，不是少数重轮的偶发事件。均匀税 → 全局杠杆：reasoningEffort 档位。

预钉规则（grill 共识）：质量闸门 = 判卷 ✓ **加**行为闸门（召回可及性 + 施工轮工具数不塌缩）；落地条件 = 某低档全过 → 插件默认注入该档，显式配置永不被动。

## 曲线（n1 + n2 × 四档，v4-flash，串行避免跨臂缓存挤占）

| cell | miss | hit | 输出 | 其中推理 | 成本(刊例谷时) | 判卷 |
|---|---|---|---|---|---|---|
| n1 × off | 70.4K | 66.4K | 1,441 | 0 | $0.0169 | ✓ |
| n1 × **low** | 65.2K | 69.5K | 2,165 | 607 | **$0.0163** | ✓ |
| n1 × high | 67.8K | 87.3K | 4,593 | 3,024 | $0.0186 | ✓ |
| n1 × max | 71.9K | 87.4K | 5,311 | 3,614 | $0.0199 | ✓ |
| n2 × off | 46.3K | 63.7K | 2,313 | 0 | $0.0122 | ✓ |
| n2 × **low** | 45.6K | 64.9K | 2,869 | 601 | $0.0124 | ✓ |
| n2 × high | 46.3K | 85.0K | 5,579 | 3,087 | $0.0145 | ✓ |
| n2 × max | 46.6K | 94.6K | **19,740** | 11,947 | $0.0239 | ✓ |

- **low 砍约一半输出 token**，两场景总价 −12/−14%（此二场景输出仅占成本 ~20%；输出占 38–45% 的会话预期收益更大）。
- **max 有害的初步证据**：n2 出现 19.7K 输出爆炸，比 high 贵 65%，判卷无提升（单次观测，供参考）。
- 行为闸门（n2 施工轮工具数 ≥ high 半数）：四档全过（11–16 vs high 16）。

## 召回可及性探针（歧视性闸门）

n1 的"必须召回"闸门在原场景**空虚**——政策条款经 ask 头尾保留通道逐字存活于 tape，召回非必需（off/low 零召回判卷全对是合法路径，非假绿）。

`scripts/probe-recall-affordance.mts`：让模型自己发明 `KESTREL-<4位数字>` 码字埋进 >7K 字符回复的**头尾截断中段**（指令原文不含答案，唯一出现），T2 中性提问逐字原句。

| effort | 主动调用 recall_turn | 码字正确 |
|---|---|---|
| low | **✓** | ✓ |
| high | ✓ | ✓ |

**low 档在召回真必需时探索未塌缩** → 闸门按意图通过。

> 探针设计教训（记录在案）：v1 把码字写进指令原文——ask 头尾全保留，low 档从 ask 直接重建答案，探针空虚；v2 改为模型自发明 + 唯一性校验（重复出现会漏进保留区）。做召回类判据时，答案不得存在于任何保留通道。

## 裁决与落地

按预钉规则采纳 **low 为插件出厂默认**（`src/effort-default.ts`）：

- 注入点在 `agent/request` waterfall 之后、header 规范化之前——epoch header 如实记录生效值，logged ⟺ sent 审计不变式不破。
- **显式选择永不被动**：AgentOptions / 恢复 epoch header 的非默认值 / waterfall 上的其他插件设了 `reasoningEffort` 就原样放行；适配器默认（high）在 `requestProposal` 已剥离，不算显式。
- 退出方式：插件配置 `defaultReasoningEffort: 'inherit'`（回到适配器默认 high），或任何显式配置。
- 未触发的分支照录：动态按轮路由（轻轮降/重轮保）**不立项**——恒定 low 已过全部闸门，为未触发的需求维护机制正是本仓库删过四档保真度控制器时埋葬的错误。

## 局限

- 每 cell 单次运行；max 爆炸与 off 的工具乱撞为单次观测。临界决策（如未来想默认 off）需加跑。
- n 系列均为召回/留存型；输出占比更高的运维型长会话（原 r1/s14b 类）定义已失，收益推断自"均匀税"结构，未直接实测。
- effort 参数不动提示词字节：八臂 sidecar 归因可复核（同场景各臂分歧点结构一致）。

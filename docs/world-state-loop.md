## 实现(MVP,默认关闭)

每步请求 = `[runtime-context?][宪法 + 世界状态账本 + 相关推送](单条种子) + 最近 K 步原文热窗`。
- **宪法**:本轮请求原文 + 前 `pinSteps`(2)步读取的文件全文钉住 + 规则(原文 并且 谓词)。
  规则由一次旁路模型调用从钉住文件提取(自备 PreparedLlmCall——句柄一次性)。
- **账本**:append-only。文件日志(每次读/写追加一行,当前态 = 每路径最后一行)+ 事实账本
  (修正 = 追加新条目 + `#n supersedes #m` 行;旧行字节不动)。宿主从 tool/result 确定性提取
  (sha、动作、失败);助手正文 `decision:/obligation:/fact:` 行作为模型提议事实(出处 = 消息摘要)。
- **契约执行**:写前磁盘快照 → 写后按谓词校验 → 违反即回滚并把结果改成错误打回模型。
- **热窗** K=3,**相关性推送** 复用 recall_search 评分器。
- 离线契约测试(mock adapter + 真实临时目录):钉住/提取/账本/契约回滚/热窗全链路。

### 四个结论

**1. 提案的核心承诺在规则型任务(l1)上兑现。** 峰值 35.5K = transcript 的 1/9、
slice-seal 的 1/3;推理 6.1K 四臂最低——重定位税消失是真的(提案 W3 生死线通过)。
规则提取 15 条/5 条可执行,零弹回:宪法常驻让模型自觉守规,契约成了安全网而非拐杖。

**2. 在运行态型任务(l2)上撞墙。** 138 步、推理 50.6K、成本 4×。l2 的正确性依赖跨 45
条记录的运行态(余额连续),宿主提取不了,模型自己维护;3 步热窗下它反复重推。
**世界状态循环的适用边界:状态能被宿主提取或被模型一句话宣告的任务是主场;
需要连续计算的运行态是客场。**

**3. "按变化量计价"的假设在滑动热窗上失效。** 种子每步重建后,热窗原文位置后移、
前缀缓存全部失效——l1 miss 1.03M(transcript 的 3 倍)。K=1 把 miss 减半但正确性破:
l1 44/45(链式任务的工作集是"上一读 + 本写"= 2 步),**l2 4/45**(journal 顺序规则不可
形式化、契约拦不住,运行态随窗口滑出彻底丢失;契约弹回 4 次也救不回)。**热窗不能小于
任务的工作集,而工作集由任务决定,不由 loop 决定。**严格前缀缓存下,**任何有界上下文
方案都为滑动窗口每步付 miss,transcript 的"永不丢弃"只为新增字节付**;命中价 1/30,
盈亏平衡在热窗 < transcript/30——l1 正好在平衡点附近。

**4. 四臂全部 45/45(K=3),无 rot。** 正确性不是区分项;区分全在"怎么花钱"。

## 真实会话回放试点(Claude Code 单轮语料)

语料:199 个人类轮中严格可回放 1(026)、放宽 +1(051);提取器、INDEX、oracle 见
`results/20260902-replay/corpus`。回放 = 起始 commit 临时 worktree + `@deepseek-ai/*`
重指 rc8(老 API 时代)+ fs/search/bash 全栈。

| 案例 | 臂 | 步数 | 改动文件 | Jaccard | 相似度 | 成本 |
|---|---|---|---|---|---|---|
| 026(原 85 调用/7 文件) | transcript | 18 | 3 | 0.11 | 0.49 | $0.021 |
| 026 | slice-noseal | 13 | 2 | 0.13 | 0.49 | $0.023 |
| 026 | state | 12 | 2 | 0.13 | 0.49 | $0.060 |
| 051(原 100 调用/15 文件) | transcript | 12 | 0 | 0.00 | 0.81* | $0.004 |
| 051 | slice-noseal | 12 | 0 | 0.00 | 0.81* | $0.015 |
| 051 | state | 6 | 0 | 0.00 | 0.81* | $0.004 |

\* 0 改动时相似度 = 起始态与 oracle 的基线。

**结论:回放试点对 loop 比较无区分度。** 原轮是 Claude 用整场会话上下文做的活;flash
拿 4 次交流的背景,026 做出浅版本(三臂无差)、051 根本不执行(三臂 0 改动)。限制
因素是**模型与上下文不对等**,不是 loop。要让回放有效,需要:同模型录制的语料、或
把整场会话作为上下文、或"一句话派活"型的独立任务轮——本机语料里没有。

## 裁决

- **世界状态循环:保留为实验 mode,默认关闭。** 它在规则型长链上是四臂里峰值最低、
  推理最省的,但在运行态任务上成本失控,且在 DeepSeek 的缓存折扣下输入侧不占优。
- **可迁移的产出**:宪法常驻 + 契约执行(零弹回说明"让模型看见规则"比"事后拦"更值);
  append-only 账本渲染;旁路调用要自备 PreparedLlmCall;runner 必须传 `meta.cwd`。
- **下一步若继续**:① 热窗与账本的位置互换实验(账本尾置,热窗 append-only)以救缓存;
  ② 运行态的宿主侧提取(l2 的余额/序号可由宿主从写入内容算出——把"运行态"变成"宿主
  事实");③ 换到无缓存折扣的服务商再测一次成本。

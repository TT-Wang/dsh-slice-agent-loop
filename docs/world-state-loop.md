# 世界状态循环(World-State Loop):实现、v2 重载荷 A/B、回放试点与裁决

> 2026-09-02 · deepseek-harness-a4 · deepseek-v4-flash · effort low
> 提案:docs/plans 同名提案(2026-09-02);实现:`src/slice/state-ledger.ts` + driver `mode: 'state'`

## 实现(MVP,默认关闭)

每步请求 = `[runtime-context?][宪法 + 世界状态账本 + 相关推送](单条种子) + 最近 K 步原文热窗`。
- **宪法**:本轮请求原文 + 前 `pinSteps`(2)步读取的文件全文钉住 + 规则(原文 并且 谓词)。
  规则由一次旁路模型调用从钉住文件提取(自备 PreparedLlmCall——句柄一次性)。
- **账本**:append-only。文件日志(每次读/写追加一行,当前态 = 每路径最后一行)+ 事实账本
  (修正 = 追加新条目 + `#n supersedes #m` 行;旧行字节不动)。宿主从 tool/result 确定性提取
  (sha、动作、失败);助手正文 `decision:/obligation:/fact:` 行作为模型提议事实(出处 = 消息摘要)。
- **契约执行**:写前磁盘快照 → 写后按谓词校验 → 违反即回滚并把结果改成错误打回模型。
- **热窗** K=3,**相关性推送** 复用 recall_search 评分器。
- 离线契约测试(mock adapter + 真实临时目录):钉住/提取/账本/契约回滚/热窗全链路。

### 四个结论

**1. 提案的核心承诺在规则型任务(l1)上兑现。** 峰值 35.5K = transcript 的 1/9、
slice-seal 的 1/3;推理 6.1K 四臂最低——重定位税消失是真的(提案 W3 生死线通过)。
规则提取 15 条/5 条可执行,零弹回:宪法常驻让模型自觉守规,契约成了安全网而非拐杖。

**2. 在运行态型任务(l2)上撞墙。** 138 步、推理 50.6K、成本 4×。l2 的正确性依赖跨 45
条记录的运行态(余额连续),宿主提取不了,模型自己维护;3 步热窗下它反复重推。
**世界状态循环的适用边界:状态能被宿主提取或被模型一句话宣告的任务是主场;
需要连续计算的运行态是客场。**

**3. "按变化量计价"的假设在滑动热窗上失效。** 种子每步重建后,热窗原文位置后移、
前缀缓存全部失效——l1 miss 1.03M(transcript 的 3 倍)。K=1 把 miss 减半但正确性破:
l1 44/45(链式任务的工作集是"上一读 + 本写"= 2 步),**l2 4/45**(journal 顺序规则不可
形式化、契约拦不住,运行态随窗口滑出彻底丢失;契约弹回 4 次也救不回)。**热窗不能小于
任务的工作集,而工作集由任务决定,不由 loop 决定。**严格前缀缓存下,**任何有界上下文
方案都为滑动窗口每步付 miss,transcript 的"永不丢弃"只为新增字节付**;命中价 1/30,
盈亏平衡在热窗 < transcript/30——l1 正好在平衡点附近。

**4. 四臂全部 45/45(K=3),无 rot。** 正确性不是区分项;区分全在"怎么花钱"。

## 裁决(v2 时点;v3 见文末)

- **世界状态循环:保留为实验 mode,默认关闭。** 它在规则型长链上是四臂里峰值最低、
  推理最省的,但在运行态任务上成本失控,且在 DeepSeek 的缓存折扣下输入侧不占优。
- **可迁移的产出**:宪法常驻 + 契约执行(零弹回说明"让模型看见规则"比"事后拦"更值);
  append-only 账本渲染;旁路调用要自备 PreparedLlmCall;runner 必须传 `meta.cwd`。
- **下一步若继续**:① 热窗与账本的位置互换实验(账本尾置,热窗 append-only)以救缓存;
  ② 运行态的宿主侧提取(l2 的余额/序号可由宿主从写入内容算出——把"运行态"变成"宿主
  事实");③ 换到无缓存折扣的服务商再测一次成本。

# v3 追加流(mode: 'stream'):推翻热窗,保留宪法与契约

> 2026-09-02 下午 · 目标:在正确与便宜上全面超越 transcript 与 slice,峰值不设限;
> 方法:实验 → 改进 → 实验。实现:`src/slice/result-digest.ts` + driver `mode: 'stream'`

## 设计:从上面四个结论倒推

结论 3 说:严格前缀缓存下,任何有界上下文方案都为滑动窗口每步付 miss,"永不丢弃"只为
新增字节付。那就不要窗口——轮内 append-only(缓存完美),成本杠杆全部压到**每步新增
字节**上:

- **注入时摘要(insertion-time digest)**:大工具结果进上下文之前折成紧凑视图——头/尾若干
  行 + 全部结构行(`key = value` / `key: value` / 标题 / 段标记)+ 精简省略标记
  `…[+N lines / M chars]…`;视图头行写明 `recall_step(t, s) returns the full text`,全文原样
  留在会话日志。守卫:< 1500 字符不折;折后 ≥ 原文 55% 不折;**钉住步(前 2 步)的读取不折**
  (它们是本轮的规则来源)。头部区外每个连续结构行块可设上限(`structuredBlockCap`)。
- **宪法**只追加一次(请求 + 钉住清单 + 提取的规则),不重建种子;钉住文件全文已在流里。
- **契约**保留,但加**弹回预算**:同一规则打回一次后再违反,判定谓词更可能错——谓词停用、
  写入放行、附宿主提示让模型对照规则原文自查。
- **旁路调用**(规则提取)独立 effort 档,默认 off;用量全额入账(此前漏记)。
- **<stream> 可供性说明**(仅此模式):告诉模型折叠存在、整读不比折叠视图贵而分页每段一步、
  下一动作已定就同响应发出。
- 摘要器认 read 工具的 `N: ` 行号前缀(判结构前剥掉;首版没剥,线上退化为只留头尾)。

## 结论(到 v3.2)

1. **四个场景全对,长任务全面最便宜**(三次均值):l1 是 transcript 的 21%、slice 的 20%;l2 是
   transcript 的 23%、slice-noseal 的 57%;n3 最便宜;n2 与两者持平(差 $0.001,单次噪声)。
   不靠峰值(峰值 48–50K,是 state 臂的 1.4 倍),靠每步新增字节。
2. **成本的三分天下**:v3.2 l1 = miss $0.0075 + hit $0.0087 + out $0.0094。miss 已是"每节点一个
   折后视图"(18K 字符 → 1K);hit 是 append-only 的必然(∝ 步数 × 前缀,S²/2·g);out 的底
   是每步一次工具调用正文 + effort low 的 ~100 推理。再往下只剩推理档(off)与更少的步数
   (链式任务已到每节点一步的下限)。
3. **契约的正确用法**:谓词是廉价提取来的,不能当真理。弹回预算把它变成"最多打断你一次"的
   提醒——l1/l2 共停用 16 条错谓词,零误伤;契约从第 8 步起才执行,短轮永不被打回。
   **真正的守规靠宪法在场**:两次没有早期规则复述的 l2 运行(no-rules、惰性提取)都把
   45 个文件写错目录;有复述的三次全对。
4. **模型不知道 loop 的机制就会绕开它**:l2 v3.0 模型自发分页避开大文件,摘要一次没触发;
   一段可供性说明把 92 步变 50 步。机制要么对模型透明,要么告诉它。
5. **单次运行会骗人**:同配置推理 3–7K 波动,策略(流水 vs 先读后写)也会变,效果 ≤ 15% 的
   改动单次分不出;每一步改进都靠按步归因(sidecar 工具名 + .trace.jsonl)而不是总数。

## 裁决(v3)

- **stream 取代 state 成为世界状态循环的形态**:热窗、账本渲染、相关性推送作为实验保留在
  `mode: 'state'`,不再推进;宪法 + 契约(带弹回预算、第 8 步起执行)+ 注入时摘要 +
  可供性说明是 v3 的全部。插件默认仍是 `mode: 'slice'`(字节稳定的现状);建议把
  `mode: 'stream'` 作为长任务宿主的默认——一行配置。
- **不做的**:轮内封存(缓存折扣下不划算,见上)、更小的热窗(工作集由任务决定)、
  更激进的摘要(结构块上限 4 已把视图压到原文 5–6%;再压要动字段本身)。
- **可选的下一档**:主调用 effort off(阶梯实验里 n1/n2 合法通过,但有"工具乱撞"单次观测),
  预计再省 ~$0.003/场景;交叉验证扩到更多多轮语料后再定默认。
